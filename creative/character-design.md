# Character Design

**Category:** creative
**Model:** Claude / GPT-4
**Use case:** Create detailed, memorable characters for stories, games, or RPGs

## Prompt

Create a character for a [genre: fantasy / sci-fi / cyberpunk / historical] setting.

Archetype: [protagonist / antagonist / mentor / sidekick / villain]
Role: [describe their function in the story]

Include:
1. Name and nickname
2. Physical description (age, appearance, distinguishing features)
3. Personality (MBTI, virtues, flaws, secrets)
4. Backstory (origin, pivotal event, motivation)
5. Skills and abilities
6. Speech patterns / catchphrases
7. Relationships (allies, enemies, love interest)
8. Arc (how they change throughout the story)

## Expected Output

A complete character profile ready for use in writing or game development.

## Tips

- Specify the tone (gritty, humorous, epic) for consistency
- Ask for dialogue samples to nail their voice
- Request an "opposite" version for alternative storylines
- Mention existing characters for reference (e.g., "like Han Solo but a librarian")
