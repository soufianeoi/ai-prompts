# Explain Code

**Category:** coding
**Model:** Any LLM
**Use case:** Understand complex code you didn't write or haven't seen before

## Prompt

Explain this code to me like I'm a [junior / mid-level / senior] developer:

```
[Paste code here]
```

Cover:
1. What does this code do at a high level?
2. What's the architecture / design pattern?
3. What are potential issues or gotchas?
4. How could it be improved?

## Expected Output

A plain-English explanation of the code's purpose, architecture, pitfalls, and improvement suggestions.

## Tips

- Specify your experience level for appropriate depth
- Mention the language/framework if not obvious
- Ask for a diagram description if the logic is complex
