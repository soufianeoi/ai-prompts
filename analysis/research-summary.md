# Research Summary

**Category:** analysis
**Model:** Claude / GPT-4
**Use case:** Summarize long research papers, articles, or reports into digestible insights

## Prompt

Summarize this [article / paper / report] for a [technical / general] audience:

```
[Paste text or URL content]
```

Provide:
1. One-sentence TL;DR
2. Key findings (3-5 bullet points)
3. Methodology overview (1-2 sentences)
4. Limitations or caveats
5. Practical takeaways
6. Related work or further reading suggestions

## Expected Output

A structured summary that captures the essence without requiring the reader to open the original.

## Tips

- Include the publication year and source for credibility
- Ask for critical evaluation, not just summary
- Specify output length (brief vs. comprehensive)
- Request reference links if analyzing multiple sources
