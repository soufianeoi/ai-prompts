## Prompt Format

Each prompt follows this structure:

`markdown
# Title

**Category:** category
**Model:** GPT-4 / Claude / etc.
**Use case:** What this solves

## Prompt

`
The actual prompt text here
`

## Expected Output

What you should expect from a good response.

## Tips

- Parameter adjustments
- Model-specific notes
- Variations to try
`

## Usage

Browse the category folders and copy prompts directly. Adjust parameters (temperature, max tokens) based on your model and use case.
