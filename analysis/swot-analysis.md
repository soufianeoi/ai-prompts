# SWOT Analysis

**Category:** analysis
**Model:** Any LLM
**Use case:** Analyze the strengths, weaknesses, opportunities, and threats of a project or business

## Prompt

Perform a SWOT analysis on [project / business / idea]:

Context:
- What it is: [description]
- Industry/market: [industry]
- Current stage: [idea stage / early / growing / mature]
- Key competitors: [competitors]

Structure:
1. **Strengths** (internal, positive) — 3-5 points
2. **Weaknesses** (internal, negative) — 3-5 points
3. **Opportunities** (external, positive) — 3-5 points
4. **Threats** (external, negative) — 3-5 points

For each point, include a brief explanation and a suggested action.

## Expected Output

A complete SWOT matrix with actionable recommendations for each quadrant.

## Tips

- Be brutally honest about weaknesses — that's where growth happens
- Include market trends and timing in opportunities
- Consider regulatory and competitive threats
- Ask for a TOWS analysis (matching strengths to opportunities, etc.)
