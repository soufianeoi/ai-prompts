# Game Mechanic Design

**Category:** creative
**Model:** Any LLM
**Use case:** Design balanced, fun game mechanics with clear rules

## Prompt

Design a game mechanic for a [genre] game.

Core loop: [what the player does repeatedly]
Target feeling: [powerful / strategic / creative / tense / relaxed]
Platform: [PC / console / mobile / tabletop]

Design the mechanic:
1. **Name** — catchy and descriptive
2. **Description** — how it works in 2-3 sentences
3. **Input** — what the player does (button press, drag, command)
4. **Rules** — exact logic, cooldowns, costs, limitations
5. **Progression** — how it evolves or unlocks
6. **Synergies** — how it interacts with other mechanics
7. **Failure state** — what happens when used poorly
8. **Accessibility** — considerations for different skill levels

## Expected Output

A complete mechanic design with rules, progression, synergies, and accessibility notes.

## Tips

- Reference existing games for clarity ("like the hookshot in Zelda")
- Mention your target player skill level (casual, hardcore)
- Ask for edge cases and exploits to test balance
- Request animation or feedback ideas (sound, visual, haptic)
