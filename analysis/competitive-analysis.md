# Competitive Analysis

**Category:** analysis
**Model:** GPT-4 / Claude
**Use case:** Analyze competitors to find gaps and opportunities

## Prompt

Perform a competitive analysis for [my product/company] in the [industry/market].

My product: [description]
Target market: [audience]
Key differentiator: [what makes you unique]

Analyze these competitors:
- Competitor A: [what they do]
- Competitor B: [what they do]
- Competitor C: [what they do]

For each competitor, evaluate:
1. Product features (strengths and weaknesses)
2. Pricing model
3. Target audience
4. Market positioning
5. UX / design quality
6. Customer reviews (common praise and complaints)

Then provide:
- Feature comparison matrix
- Market gap analysis (what's underserved)
- Strategic recommendations
- Pricing strategy advice

## Expected Output

Structured competitive analysis with comparison matrix, gap analysis, and actionable recommendations.

## Tips

- Provide URLs or specific details for more accurate analysis
- Include review scores from G2/Capterra/Trustpilot if available
- Ask for a positioning statement you can use
- Include a "blue ocean" suggestion (untapped market space)
