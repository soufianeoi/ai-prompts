# Brainstorming Session

**Category:** creative
**Model:** Any LLM (high temperature: 0.9+)
**Use case:** Generate diverse ideas, solutions, or concepts for open-ended problems

## Prompt

I need ideas for [topic / problem / project].

Context:
- Goal: [what I'm trying to achieve]
- Constraints: [budget, time, tech, skills]
- Audience: [who it's for]
- What I've already considered: [list]

Please generate:
1. 10 wild ideas (don't filter, just generate)
2. 5 practical ideas (feasible with my constraints)
3. 3 "blue ocean" ideas (unconventional approaches)
4. For the top 3 ideas: a brief execution plan

Be creative! I'd rather have weird ideas I can tone down than safe ideas that go nowhere.

## Expected Output

A diverse set of ideas with varying levels of ambition, plus execution sketches for the best ones.

## Tips

- Set temperature to 0.9+ for maximum creativity
- Try multiple rounds: build on the best ideas from round 1
- Ask for "worst possible idea" to get unstuck
- Request mashups of existing concepts
