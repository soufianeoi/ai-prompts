# World Building

**Category:** creative
**Model:** Claude / GPT-4
**Use case:** Build immersive, consistent fictional worlds for stories or games

## Prompt

Build a fictional world for a [genre] setting.

Core concept: [one-sentence premise]
Tone: [hopeful / dark / whimsical / grounded]
Technology level: [medieval / steampunk / modern / sci-fi / post-apocalyptic]
Magic system: [none / soft / hard rules]

Include:
1. Geography (continents, climate, notable locations)
2. History (origin myth, major events, current era)
3. Society (government, social classes, laws, currency)
4. Culture (language, religion, art, food, customs)
5. Technology and magic (how it works, limitations, cost)
6. Factions (groups, guilds, nations, their goals and conflicts)
7. Daily life (what ordinary people do, economy)
8. Conflict (central tension driving the story)

## Expected Output

A comprehensive world bible with interconnected systems and built-in story hooks.

## Tips

- Ask for a "rule of cool" vs. realism balance
- Request a map description or coordinate system
- Inconsistencies should be flagged
- Mention existing worlds for inspiration (e.g., "like Middle-earth but ocean-based")
