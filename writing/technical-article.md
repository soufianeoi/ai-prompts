# Write a Technical Article

**Category:** writing
**Model:** Claude / GPT-4
**Use case:** Draft a clear, engaging technical blog post or tutorial

## Prompt

Write a technical article about [topic] targeting [audience level: beginner / intermediate / advanced].

Title: [suggest or provide]

Structure:
1. Hook / opening paragraph that grabs attention
2. Problem statement — what gap does this fill?
3. Step-by-step walkthrough with code examples
4. Common pitfalls and how to avoid them
5. Summary and next steps

Tone: [professional / conversational / tutorial-style]
Length: ~[X] words

## Expected Output

A complete article with headings, code blocks, and a call-to-action at the end.

## Tips

- Provide 3-5 specific keywords for SEO
- Mention related technologies for context
- Ask for a TL;DR section at the top
