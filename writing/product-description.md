# Write a Product Description

**Category:** writing
**Model:** Any LLM
**Use case:** Craft compelling product copy that converts

## Prompt

Write a product description for [product name], which is a [one-line description].

Target audience: [demographic]
Platform: [Amazon / Shopify / landing page / etc.]
Tone: [professional / playful / luxurious / minimalist]

Include:
1. Headline (max 10 words)
2. 3-5 bullet points of key features
3. Benefits paragraph (how it solves their problem)
4. Technical specs (if applicable)
5. Call to action

## Expected Output

Ready-to-use product copy with headline, features, benefits, specs, and CTA.

## Tips

- Mention specific numbers (weight, size, speed, capacity)
- Include social proof elements (e.g., "10k+ sold")
- Focus on benefits, not just features
- Optimize for search terms relevant to the product
