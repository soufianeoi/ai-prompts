# Dialogue Writing

**Category:** creative
**Model:** Claude / GPT-4
**Use case:** Write natural, character-appropriate dialogue for scenes

## Prompt

Write a dialogue scene between [Character A] and [Character B].

Setting: [location and situation]
Mood: [tense / humorous / romantic / confrontational / casual]
Character A: [personality, speech style, goal in this scene]
Character B: [personality, speech style, goal in this scene]
Subtext: [what each character is NOT saying]

Length: ~[X] lines of dialogue

Rules:
- No exposition dumps — reveal info naturally
- Each character should have a distinct voice
- Show don't tell emotions through word choice and rhythm
- Include action beats (she laughed, he looked away) between lines

## Expected Output

A formatted script-style dialogue with character names, lines, and action beats.

## Tips

- Provide a sample of each character's speech for voice consistency
- Mention accents, slang, or verbal tics
- Ask for the same scene written from different character perspectives
- Request a subtext breakdown after the scene
