# Debate Analysis

**Category:** reasoning
**Model:** Claude / GPT-4
**Use case:** Analyze both sides of an argument objectively and find common ground

## Prompt

Analyze the following debate topic from multiple perspectives:

Topic: [statement or question]

**Side A: [Pro / Side A label]**
- Main argument
- Key evidence
- Strongest point
- Weakest point
- Emotional appeal

**Side B: [Con / Side B label]**
- Main argument
- Key evidence
- Strongest point
- Weakest point
- Emotional appeal

Then provide:
1. Points of agreement (areas of common ground)
2. Unresolved factual disputes (what could be settled with data)
3. Logical fallacies on either side
4. A nuanced synthesis — what a reasonable person should conclude

## Expected Output

A balanced, dispassionate analysis of both sides with logical evaluation and synthesis.

## Tips

- Specify if you want a "steel man" (best version) of each side
- Ask for the strongest counter-argument to your own position
- Request citations or sources for factual claims
- Keep the temperature low (0-0.3) for objectivity
